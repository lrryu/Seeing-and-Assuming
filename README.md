# Source-attribution audit — interactive narrative

A single-file interactive page for the study *“A source-attribution audit of
vision-language models for urban land-use mapping from street view imagery.”*

Open `index.html` in a browser, or enable GitHub Pages
(Settings → Pages → Deploy from branch, root folder). No build step, asset
directory or server is required.

- One file, 0.84 MB; no external requests; works from `file://`.
- Figures 1–9 are native HTML/SVG views, not embedded figure rasters; the six
  condition samples are the only inline images.
- English only; the file contains no Chinese text and no language switch.
- Author names, affiliations and contact details are omitted in this version.

Optional URL parameters: `?section=s01`–`s08`, `?static=1`.
